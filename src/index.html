ส่วน A · ที่เครื่อง: เปิดโหมดนักพัฒนา
1
เปิด การตั้งค่า (Settings)
2
แตะ เกี่ยวกับโทรศัพท์ (About phone)อยู่ล่างสุด
3
แตะ หมายเลขบิวด์ (Build number) 7 ครั้ง ติดกันหาไม่เจอ: พิมพ์ "บิวด์" ในช่องค้นหาของการตั้งค่า
4
ขึ้น "คุณเป็นนักพัฒนาแล้ว" = สำเร็จ ✅
ส่วน B · ที่เครื่อง: เปิด USB debugging
1
การตั้งค่า > ระบบ > ตัวเลือกสำหรับนักพัฒนาหาไม่เจอ: พิมพ์ "นักพัฒนา" ในช่องค้นหา
2
เปิดสวิตช์ การแก้ไขข้อบกพร่อง USB (USB debugging) แล้วกด ตกลง
ไม่มีเมนูนี้ หรือสวิตช์เป็นสีเทา = บริษัทล็อกไว้ ให้แจ้งไอที Flash
ส่วน C · ที่คอม: เชื่อมต่อ
1
เสียบสาย USB · ปลดล็อกหน้าจอเครื่อง
2
กดปุ่มสีฟ้า + เชื่อมต่อเครื่อง ด้านบน
3
คลิกชื่อเครื่อง แล้วกด เชื่อมต่อ
4
ที่เครื่อง: ติ๊ก อนุญาตเสมอ แล้วกด อนุญาต ✅
ครั้งต่อไป แค่เสียบสาย เว็บจะต่อให้เอง
❓ ติดปัญหา? กดดูวิธีแก้

ไม่เห็นชื่อเครื่องในหน้าต่าง

  1. เช็กว่าเปิด USB debugging แล้ว (ส่วน B)
  2. เปลี่ยนสาย หรือเปลี่ยนช่อง USB
  3. ถอดสาย รอ 3 วินาที เสียบใหม่

ขึ้นว่า "เครื่องถูกใช้อยู่"

  1. กดปุ่ม ⊞ Windows พิมพ์ cmd กด Enter
  2. พิมพ์ cd C:\Users\Flash\Desktop\Best\platform-tools กด Enter
  3. พิมพ์ adb kill-server กด Enter
  4. ปิดแท็บเว็บนี้ที่เปิดซ้ำ แล้วเสียบสายใหม่
⬇️ โหลด Platform-Tools

ไม่มีหน้าต่าง "อนุญาต" ที่เครื่อง

  1. ปลดล็อกหน้าจอเครื่อง แล้วถอดสายเสียบใหม่
  2. ถ้าเคยกดปฏิเสธ: ตัวเลือกสำหรับนักพัฒนา > เพิกถอนการให้สิทธิ์การแก้ไขข้อบกพร่อง USB

ไม่อยากกดอนุญาตใหม่ทุก 7 วัน

ตัวเลือกสำหรับนักพัฒนา > เปิด ปิดการหมดเวลาการให้สิทธิ์ adb (ถ้ามี)
