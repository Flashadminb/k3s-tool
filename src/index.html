ส่วน B · ที่เครื่อง: เปิด USB debugging
1
Settings > System (ระบบ) > Developer options (ตัวเลือกสำหรับนักพัฒนา)หาไม่เจอ: พิมพ์ "developer" ในช่อง Search
2
สวิตช์บนสุด Use developer options (ใช้ตัวเลือกสำหรับนักพัฒนา) ต้องเป็นสีน้ำเงิน (เปิด)
3
เลื่อนลงไปเรื่อยๆ จนเจอหัวข้อ Debugging (การแก้ไขข้อบกพร่อง)อยู่ค่อนข้างลึก ต้องเลื่อนผ่าน Memory, Bug report, Stay awake ฯลฯ ก่อน · หรือกดรูปแว่นขยายมุมขวาบน แล้วพิมพ์ "USB debugging"
4
เปิดสวิตช์ USB debugging (การแก้ไขข้อบกพร่อง USB) ให้เป็นสีน้ำเงิน แล้วกด OK (ตกลง)
5
เลื่อนลงต่อ หา Default USB configuration (การตั้งค่า USB เริ่มต้น) แล้วเลือก File transfer (โอนไฟล์)ถ้าเป็น Charging only (ชาร์จอย่างเดียว) คอมอาจมองไม่เห็นเครื่อง
6
(แนะนำ) ถ้ามี Disable adb authorization timeout ให้เปิดด้วยจะได้ไม่ต้องกด Allow ใหม่ทุก 7 วัน · ไม่มีก็ข้ามได้
7
เสียบสาย USB แล้วรูดแถบแจ้งเตือนลงมา ต้องเห็น USB debugging connected = พร้อมแล้ว
ไม่มีเมนูนี้ หรือสวิตช์เป็นสีเทา = บริษัทล็อกไว้ ให้แจ้งไอที Flash

4
ที่เครื่องขึ้น Allow USB debugging? (อนุญาตไหม): ติ๊ก Always allow from this computer (อนุญาตจากคอมนี้เสมอ) แล้วกด Allow (อนุญาต)
ครั้งต่อไป แค่เสียบสาย เว็บจะต่อให้เอง
กดเชื่อมต่อแล้ว ไม่เห็นชื่อเครื่องในหน้าต่าง
1
ดูที่ดาวกลางจอก่อนถ้าเครื่องขึ้นเป็นดาวอยู่แล้ว แปลว่าต่ออยู่แล้ว ไม่ต้องกดซ้ำ (Chrome จะไม่แสดงเครื่องที่เว็บนี้ใช้อยู่)
2
รูดแถบแจ้งเตือนที่เครื่องลงมา ต้องเห็น USB debugging connected (เชื่อมต่อการแก้ไขข้อบกพร่อง USB แล้ว)ถ้าไม่เห็น: USB debugging ปิดอยู่ (เช่นเพิ่งรีเซ็ต) ให้ทำส่วน B ใหม่ หรือสายเสีย/เป็นสายชาร์จอย่างเดียว ให้เปลี่ยนสาย
3
ในแถบแจ้งเตือน แตะข้อความ USB แล้วเลือก File transfer (โอนไฟล์)บางเครื่องโหมด Charging only (ชาร์จอย่างเดียว) จะไม่ให้คอมเห็นเครื่อง
4
ปิดแท็บอื่นที่เปิดเว็บนี้ซ้ำ และปิดโปรแกรมอื่นที่ใช้มือถือ แล้วถอดสาย รอ 3 วินาที เสียบใหม่
5
ยังไม่เจอ: เช็กด้วย adb ตามหัวข้อ เช็กด้วย adb ด้านล่าง
ติดปัญหาอื่น? กดดูวิธีแก้

เช็กด้วย adb (ใช้บอกว่าปัญหาอยู่ที่เครื่อง หรือที่เบราว์เซอร์)

  1. กดปุ่ม ⊞ Windows พิมพ์ cmd กด Enter
  2. พิมพ์ cd C:\Users\Flash\Desktop\Best\platform-tools กด Enter
  3. พิมพ์ adb devices กด Enter
  4. ขึ้นรหัสเครื่องตามด้วย device = เครื่องปกติ ให้พิมพ์ adb kill-server กด Enter แล้วกลับมากดเชื่อมต่อในเว็บ
  5. ขึ้น unauthorized = ยังไม่ได้กด Allow ที่เครื่อง
  6. ไม่ขึ้นอะไรเลย = ปัญหาที่สาย, ช่อง USB หรือ USB debugging ปิดอยู่

ขึ้นว่า "เครื่องถูกใช้อยู่"

  1. กดปุ่ม ⊞ Windows พิมพ์ cmd กด Enter
  2. พิมพ์ cd C:\Users\Flash\Desktop\Best\platform-tools กด Enter
  3. พิมพ์ adb kill-server กด Enter
  4. ปิดแท็บเว็บนี้ที่เปิดซ้ำ แล้วเสียบสายใหม่
