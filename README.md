# IDATA TOOLS

Created by **THANAWAT PHUTTARIT** · © 2026 THANAWAT PHUTTARIT

หน้าเว็บสำหรับเปิดใน Chrome/Edge บนคอม แล้วเสียบสาย USB กับเครื่อง PDA (iData K3S / Flash Kit) เพื่อลบรูปและขยะที่ทำให้พื้นที่เต็ม
ดูแลเครื่อง จัดการแอป ต่อ Wi-Fi และตั้งค่าเครื่อง โดยไม่ต้องพิมพ์คำสั่ง ทำทีละเครื่องหรือเป็นกลุ่มได้
ใช้ WebUSB + ไลบรารี `@yume-chan/adb` (ไม่ต้องติดตั้ง adb.exe)

- **ใช้งาน:** https://flashadminb.github.io/k3s-tool/
- **หน้าตาแบบเดิม (สำรอง):** https://flashadminb.github.io/k3s-tool/classic.html
- **ตัวอย่าง (เครื่องจำลอง 15 เครื่อง ไม่ต้องเสียบสาย):** https://flashadminb.github.io/k3s-tool/preview.html

อัปเดตอัตโนมัติทุกครั้งที่ push เข้า `main` ผ่าน GitHub Actions (ชื่อ repo ยังเป็น `k3s-tool` เพื่อให้ลิงก์เดิมใช้ได้)

## สถานะ: v0.3
ทดสอบกับเครื่องจริง (iData K3S, Android 12) แล้ว: เชื่อมต่อ, อ่านข้อมูลเครื่อง, หน้าตั้งวอลเปเปอร์
ฟีเจอร์อื่นผ่านชุดทดสอบเครื่องจำลอง (`npm test`, 49 ข้อ, คำสั่ง shell รันจริงบนโฟลเดอร์ปลอม) แต่ยังต้องลองกับเครื่องจริงทีละปุ่ม

## หน้าจอ
- **กลางจอ:** วงกลมเชื่อมต่อ เครื่องที่ต่อแล้วลอยอยู่รอบๆ (รองรับ 15 เครื่องไม่บังกัน) วงแหวนทอง = พื้นที่ที่ใช้ ในวงกลมมีแบต (เขียว/เหลือง/แดง) ป้าย: จอดับ (แตะเพื่อเปิด), Flash Kit ไม่มี/เก่า, แอปต้องห้าม
- **ซ้ายบน:** ชี้ที่เครื่อง = ดูข้อมูล, คลิก = ล็อกเครื่องนั้น
- **เลือกเครื่อง (ใต้วงกลม):** แตะเครื่องเพื่อเข้ากลุ่ม (มีเส้นทองเชื่อม) ทุกคำสั่งจะทำกับทั้งกลุ่มไม่ว่าอยู่เมนูไหน จนกว่าจะกด ล้างกลุ่ม · แถบล่างแสดงตัวเลขรวม
- **ด้านบน:** เมนูหลัก · ปุ่มโหลด Flash Kit
- **ด้านขวา:** รายละเอียดของเมนูที่เลือก (เลื่อนได้)
- **ด้านล่าง:** ปุ่มสำคัญ ลบรูปที่ส่งแล้ว / ล้างถังขยะ / ลบทั้งหมด / นับใหม่
- **พื้นหลัง:** กาแล็กซีเคลื่อนไหว ปรับอัตโนมัติตามความแรงของคอม (ตั้งค่า > พื้นหลัง: เต็มที่ / ประหยัด / ภาพนิ่ง)

## ทำอะไรได้บ้าง
| เมนู | ฟีเจอร์ |
|---|---|
| ลบข้อมูล (หลัก) | นับรูป success, fail, ขยะ · ลบ success · ล้างถังขยะ .trashed · ลบทั้งหมด (success+fail+ขยะ) · ลบ fail (เตือน+ยืนยัน) · เก็บรูป fail ลงคอมก่อนลบ · ล้างแคช · หาไฟล์ใหญ่สุด · ลบอัตโนมัติทุก 15/30/60/120 นาที |
| เครื่อง | แบต, Android, RAM, เวอร์ชัน Flash Kit · ภาพ/วิดีโอหน้าจอ · ดู/คุมหน้าจอสด · รีสตาร์ทแอป Flash / เครื่อง · log ส่งไอที · ติดตั้ง/อัปเดต APK · ส่งรูปหน้าจอ · **พิมพ์รหัส/ข้อความเข้าเครื่อง** (เช่นรหัส iLauncher ทีละหลายเครื่อง) · รีเซ็ต |
| แอป | รายชื่อแอป + ค้นหา · ถอน · คืนแอประบบ · แอปบริษัท/MDM/Flash ถอนไม่ได้ · แอปต้องห้าม |
| Wi-Fi | สถานะ Wi-Fi ของแต่ละเครื่อง · ค้นหา Wi-Fi ที่เครื่องเห็น · บันทึก Wi-Fi ที่ใช้บ่อย แล้วกดต่อทีเดียว (เครื่องเดียวหรือทั้งกลุ่ม) |
| ตั้งค่า | ชุดตั้งค่ามาตรฐาน · ลิงก์โหลดและเวอร์ชันล่าสุดของ Flash Kit · พื้นหลัง · ที่เก็บรูปแยกตามรุ่น |
| ประวัติ | ทะเบียนทุกเครื่อง · ประวัติการลบ · CSV เปิดใน Excel |
| คู่มือ | เปิด USB debugging ทีละขั้น · แก้ปัญหา |

ข้อมูล (ประวัติ, ทะเบียน, ตั้งค่า, Wi-Fi ที่บันทึก) เก็บใน localStorage ของเบราว์เซอร์บนคอมเครื่องนั้นเท่านั้น
รหัส Wi-Fi ไม่ได้เข้ารหัส: อย่าบันทึกบนคอมที่ใช้ร่วมกับคนอื่น · รหัสที่พิมพ์ส่งเข้าเครื่องไม่ถูกบันทึก

## วิธีพัฒนา
```
npm install
npm run build        # dist/k3s-tool.html (หน้าหลัก) + dist/classic.html (หน้าเดิม)
npm test             # ทดสอบกับเครื่องจำลอง (ต้องมี Playwright + Chromium)
node test/build-preview.mjs   # dist/preview.html เครื่องจำลองในเบราว์เซอร์
```
ก่อนใช้ต้องปิด `adb.exe` ที่รันค้าง (`adb kill-server`) ไม่งั้นเว็บจะขึ้นว่าเครื่องถูกใช้อยู่ (BUSY)

## โครงสร้าง
- `src/adb.js`  ชั้นต่อ ADB: `Device` (sh, push, pull, pullMany, reboot) หลายเครื่องพร้อมกัน, เชื่อมต่ออัตโนมัติ
- `src/app.js`  ทุกปุ่ม, กลุ่มเครื่อง, วางตำแหน่งดาว, Wi-Fi, คู่มือแก้ปัญหา (ตาราง `HELP`)
- `src/store.js`  localStorage: รุ่นเครื่อง, ประวัติ, ทะเบียน, แอปต้องห้าม, ตั้งค่ามาตรฐาน, Flash Kit, Wi-Fi, CSV
- `src/appnames.js`  ชื่อแอปที่คนเห็น + แอปห้ามถอน
- `src/index.html`  หน้าหลัก (ธีมอวกาศ + พื้นหลัง canvas) · `src/classic.html` หน้าเดิม
- `test/`  เครื่องจำลอง (`mock-adb.js`, `preview-sim.js`) + ชุดทดสอบ Playwright (`run.mjs`)
- `PRODUCT.md`, `.impeccable/`  บันทึกผู้ใช้/เป้าหมาย และแนวทางดีไซน์

## คำสั่งที่ใช้บนเครื่อง (จุดที่ต้องเช็กกับเครื่องจริง)
| ปุ่ม | คำสั่ง | หมายเหตุ |
|---|---|---|
| นับ | `find DIR -type f -exec du -k {} + \| awk` , `df -k /sdcard` | ไฟล์เป็นหมื่นอาจช้า |
| ลบ success / fail | `find DIR -type f -delete` | ไม่ใช้ `rm -rf dir/*` · ไม่มีโฟลเดอร์ = ไม่มีอะไรลบ |
| ลบขยะ | `find /sdcard -type f -name '.trashed-*' -delete` | ข้ามถังขยะ |
| สถานะจอ/แบต (ทุก 15 วิ) | `dumpsys power \| grep mWakefulness`, `dumpsys battery` | |
| เปิดจอ / จอเปิดค้าง | `input keyevent 224`, `svc power stayon usb` | ถามก่อนทุกครั้ง |
| พิมพ์รหัส | `input text`, `input keyevent 66` | ภาษาอังกฤษ/ตัวเลขเท่านั้น |
| Wi-Fi | `cmd wifi status / start-scan / list-scan-results / connect-network SSID wpa2 PASS`, `svc wifi enable` | Android 11+ · ถ้าบริษัทล็อก Wi-Fi จะต่อไม่ได้ |
| แอป | `pm list packages`, `pm uninstall`, `pm uninstall -k --user 0`, `cmd package install-existing` | แอปใน `dumpsys device_policy` และชื่อมี flash ถอนไม่ได้ |
| ติดตั้ง APK | push ไป `/data/local/tmp/` แล้ว `pm install -r` | อัปเดตทับได้ ลดเวอร์ชันไม่ได้ |
| รูปหน้าจอ | push ไป `/sdcard/Pictures/`, `content query` หา id, `am start -a android.service.wallpaper.CROP_AND_SET_WALLPAPER` | กดยืนยันที่เครื่อง 1 ครั้ง |
| รีเซ็ตเครื่อง | `am broadcast -a android.intent.action.FACTORY_RESET -p android` | น่าจะโดนปฏิเสธสิทธิ์ แล้วแสดงวิธีทำมือ |

## สิ่งที่ยังต้องทำ / เสี่ยง
1. ทดสอบกับเครื่องจริงทุกปุ่ม แล้วแก้ตามผล (โดยเฉพาะ Wi-Fi, จอดับ, พิมพ์รหัส iLauncher)
2. iLauncher: ตอนนี้พิมพ์รหัสให้เมื่อหน้าใส่รหัสเปิดอยู่ ถ้าจะให้เปิดหน้าใส่รหัสเองด้วย ต้องรู้ขั้นตอนปลดล็อกของ iLauncher ก่อน
3. Wireless ADB: รอไอทีให้คอมกับเครื่องอยู่ Wi-Fi วงเดียวกัน
4. ถ้าระบบบริษัท (MDM) บล็อกฟีเจอร์ใด ห้ามหาทางเลี่ยง ให้ปรึกษาไอที Flash
