# K3S Tool (ส่งต่อโปรเจกต์)

หน้าเว็บไฟล์เดียว ใช้เปิดใน Chrome/Edge บนคอม เสียบสาย USB กับเครื่อง K3S (Flash Kit PDA)
แล้วลบรูป/ขยะที่ทำให้พื้นที่เต็ม ติดตั้ง APK ตั้งรูปหน้าจอ และรีเซ็ตเครื่อง โดยไม่ต้องพิมพ์คำสั่ง
ใช้ WebUSB + ไลบรารี `@yume-chan/adb` (ไม่ต้องติดตั้ง adb.exe)

**เปิดใช้งาน:** https://flashadminb.github.io/k3s-tool/ (อัปเดตอัตโนมัติทุกครั้งที่ push เข้า `main` ผ่าน GitHub Actions)

## สถานะ: v0.1 ยังไม่เคยทดสอบกับเครื่อง K3S จริง
UI และ logic เขียนเสร็จและ build ผ่าน แต่ยังไม่เคยรันกับอุปกรณ์ ต้องทดสอบทุกปุ่มก่อนใช้งานจริง

## วิธีรัน
```
npm install
npm run build        # ได้ dist/k3s-tool.html (ไฟล์เดียว ไม่ต้องใช้เน็ต)
npm run serve        # หรือเปิดผ่าน http://localhost:8080 (WebUSB ต้องเป็น secure context)
```
ต้องใช้ Chrome หรือ Edge บนคอม ก่อนใช้ต้องปิด `adb.exe` ที่รันค้าง (`adb kill-server`) ไม่งั้นเว็บจะขึ้นว่าเครื่องถูกใช้อยู่ (BUSY)

## โครงสร้าง
- `src/adb.js`  ชั้นต่อ ADB: connect, sh(cmd), pushFile, disconnect
- `src/app.js`  ปุ่มทั้งหมด + ข้อความคู่มือแก้ปัญหา (ตาราง `HELP`) + dialog ยืนยัน
- `src/index.html`  หน้าจอ + คู่มือทำครั้งแรก
- `build.mjs`  bundle ด้วย esbuild แล้วฝังลง HTML เป็นไฟล์เดียว

## คำสั่งที่แต่ละปุ่มใช้ (ทดสอบทีละอัน)
| ปุ่ม | คำสั่งบนเครื่อง | หมายเหตุ |
|---|---|---|
| อัปเดตตัวเลข | `df -k /sdcard`, `find ... \| wc -l`, `du -sk` | นับไฟล์เป็นหมื่นอาจช้า ควรแสดงสถานะกำลังนับ |
| ลบ success | `find /sdcard/imagePath/success -type f -delete` | ใช้ find -delete เพราะ `rm -rf dir/*` อาจเจอ "argument list too long" เมื่อไฟล์เยอะมาก |
| ลบขยะ | `find /sdcard -type f -name '.trashed-*' -delete` | ข้ามถังขยะ ลบถาวร |
| ลบทั้งหมด | ลบ success + fail + `.trashed-*` | มีคำเตือนเรื่อง fail แล้วกดยืนยัน |
| ลบ fail | `find /sdcard/imagePath/fail -type f -delete` | รูปที่อาจยังไม่อัปโหลด ขึ้นคำเตือนแล้วกดยืนยัน (ผู้ใช้ตัดสินใจไม่ต้องพิมพ์ DELETE) |
| ล้างแคช | `pm trim-caches 999G` | อาจต้องสิทธิ์สูงกว่า shell ในบางรุ่น |
| ติดตั้ง APK | push ไป `/data/local/tmp/` แล้ว `pm install -r` | ระบบบริษัทอาจบล็อก |
| ตั้งรูปหน้าจอ | push ไป `/sdcard/Download/` แล้ว `am start -a ATTACH_DATA` | ยังไม่แน่ใจว่าตั้งอัตโนมัติได้ทุกรุ่น ตอนนี้เปิดหน้าตั้งค่าบนเครื่อง ผู้ใช้อาจต้องแตะเอง |
| รีเซ็ตเครื่อง | `am broadcast -a android.intent.action.FACTORY_RESET -p android` | เดาวิธี อาจโดนปฏิเสธสิทธิ์ ถ้าไม่ผ่านจะแสดงวิธีทำมือ ต้องยืนยัน 2 ชั้น |

## สิ่งที่ยังต้องทำ / เสี่ยง
1. ทดสอบกับ K3S จริงทุกปุ่ม (โดยเฉพาะรีเซ็ตและตั้งรูปหน้าจอ) แล้วแก้ตามผล
2. โหมดลบอัตโนมัติตามเวลา (ทุก 15/30/60 นาที ขณะเปิดหน้าเว็บ)
3. ประวัติการลบ (บันทึกลง localStorage)
4. รองรับหลายเครื่องพร้อมกัน
5. ตรวจว่ารูปใน `success` ถูกอัปโหลดแล้วจริง ก่อนลบ (ตอนนี้ถือว่า success = อัปโหลดแล้ว ตามที่เห็นในแอป)
6. ถ้าระบบบริษัท (MDM) บล็อกฟีเจอร์ใด ห้ามหาทางเลี่ยง ให้ปรึกษาไอที Flash

## ข้อควรระวังด้านความปลอดภัย
- ปุ่มลบทุกปุ่มลบถาวร (ข้ามถังขยะ) มี dialog ยืนยัน
- เปิด USB debugging เฉพาะตอนใช้งาน แล้วปิดหลังเสร็จ
- กุญแจ ADB เก็บใน IndexedDB ของเบราว์เซอร์บนคอมเครื่องนั้น
