4
เปิดสวิตช์ USB debugging แล้วกด OK (ตกลง)
5
หา Default USB configuration (การตั้งค่า USB เริ่มต้น) เลือก File transfer (โอนไฟล์)ถ้าเป็น Charging only (ชาร์จอย่างเดียว) คอมอาจมองไม่เห็นเครื่อง

(แนะนำ) ถ้ามี Disable adb authorization timeout ให้เปิดด้วยจะได้ไม่ต้องกด Allow ใหม่ทุก 7 วัน · ไม่มีก็ข้ามได้

  3. พิมพ์ adb devices กด Enter
    • ขึ้นรหัสเครื่องตามด้วย device = เครื่องปกติ
    • unauthorized = ยังไม่ได้กด Allow ที่เครื่อง
    • ไม่ขึ้นอะไร = สาย, ช่อง USB หรือ USB debugging ปิดอยู่
  4. พิมพ์ adb kill-server กด Enter แล้วกลับมาเสียบใหม่ในเว็บ

ตั้งให้จอเปิดค้างตอนเสียบสาย: แตะป้าย จอดับ ใต้วงกลม แล้วตอบ ยืนยัน
สั่งคำสั่งผิดเครื่อง / อยากหยุดคำสั่ง
1
กดปุ่ม หยุด สีแดงในกล่องสถานะกลางจอเว็บสั่งเครื่องหยุดทันที · ส่วนที่ทำไปแล้ว (เช่นรูปที่ลบไปแล้ว) ไม่ย้อนกลับ
2
ก่อนสั่ง ดูชื่อเครื่องในกรอบซ้ายบน หรือกด หาเครื่องนี้ ให้เครื่องกะพริบก่อน
อัปเดต Flash Kit ไม่ได้
1
ถ้าเว็บโหลดเองไม่ได้: Chrome จะเปิดแท็บโหลดไฟล์ รอโหลดเสร็จแล้วกด ยืนยัน แล้วเลือกไฟล์ .apk ที่ใหม่สุดใน Downloads
2
ครั้งต่อไปไม่ต้องโหลดซ้ำ: เลือก ใช้ไฟล์ที่เก็บไว้ดูวันที่โหลดล่าสุดได้ที่ ตั้งค่า > Flash Kit
3
ทางสำรอง: ตั้งค่า > Flash Kit > เลือกไฟล์ .apk ในคอม
ต่อ Wi-Fi ไม่ได้
1
เครื่อง Android รุ่นเก่า (11 ลงไป) ต่อ Wi-Fi จากคอมโดยตรงไม่ได้: เว็บจะเปิดหน้า Wi-Fi ที่เครื่องให้ แตะชื่อ Wi-Fi แล้วกด พิมพ์รหัสเข้าเครื่อง ในเว็บ
2
เครื่องรุ่นเก่าบางรุ่นต่อ 5G ไม่ได้ ให้ใช้ Wi-Fi 2.4G
เปิดเครื่องแล้วมีแต่ภาพพื้นหลัง ไม่มีไอคอน (ปุ่ม ◁ ⌂ ☰ ขึ้นปกติ)
สาเหตุที่พบบ่อย: แอปหน้าหลักถูกปิดไว้ตอนล็อกออกงาน (เว็บรุ่นก่อน) หรือเครื่องเพิ่งเปิดครั้งแรกหลังรีเซ็ตและยังโหลดไม่เสร็จ
1
ที่คอม กด Ctrl+F5
2
เสียบเครื่องทีละเครื่อง (ใช้ช่อง USB ที่จ่ายไฟพอ)
3
ถ้าเว็บต่อได้: เว็บเช็กเองว่าแอปหน้าหลักถูกปิดไหม ถ้าใช่จะเปิดคืนและกดปุ่ม Home ให้ ขึ้นกล่องเขียว "เปิดหน้าหลักของเครื่องคืนให้แล้ว" ไอคอนควรกลับมาถ้าเครื่องถามว่าจะใช้แอปไหนเป็นหน้าหลัก ให้เลือกตัวเดิม แล้วกด Always (ทุกครั้ง) · การล็อกออกงานส่วนอื่นยังอยู่ตามเดิม
4
ถ้ายังไม่มีไอคอน: แท็บ แอป > กด ปลดล็อก จะเปิดแอปที่ปิดไว้คืนทั้งหมด
ถ้าเว็บต่อไม่ได้เลย = เครื่องโดนรีเซ็ตแล้ว USB debugging ถูกปิด (การล็อกถูกล้างไปแล้ว) อาการนี้น่าจะเป็นเพราะเครื่องเพิ่งเปิดครั้งแรกและยังโหลดไม่เสร็จ: ลองกดปุ่ม ⌂ ที่เครื่อง หรือเสียบชาร์จทิ้งไว้ 10–15 นาที
เปิดเครื่องไม่ติด จอดำสนิท
1
เสียบหัวชาร์จติดผนัง (ไม่ใช่ช่อง USB คอม) ทิ้งไว้ 30 นาทีรีเซ็ตและการเปิดเครื่องครั้งแรกกินไฟมาก แบตอาจหมด · ดูว่ามีไฟสถานะหรือรูปแบตขึ้นไหม
2
กดปุ่ม Power ค้าง 15–20 วินาที ระหว่างเสียบชาร์จ
3
ถ้าถอดแบตได้: ถอดแบต รอ 10 วินาที ใส่กลับ แล้วกดเปิด
4
ลองสายหรือหัวชาร์จอื่น · ยังไม่ขึ้นอะไรเลย = ส่งศูนย์ iData (แบตหรือบอร์ด)
ค้างที่โลโก้ iData / Flash หรือวนขึ้นโลโก้ซ้ำ
1
เพิ่งรีเซ็ต: เปิดครั้งแรกใช้เวลาได้ถึง 10–20 นาที เสียบชาร์จแล้วรอ อย่ากดอะไร
2
เกิน 30 นาที: กด Power ค้าง 15 วินาทีให้ดับ แล้วเปิดใหม่
3
ยังค้าง: เข้า เมนู Recovery (หัวข้อด้านล่าง) เลือก Wipe cache partition แล้ว Reboot system now
4
ยังไม่ได้: ใน Recovery ทำ Wipe data/factory reset (ข้อมูลในเครื่องหายหมด) · ยังไม่ได้อีก = ส่งศูนย์ iData หรือไอที Flash ลงระบบใหม่
เครื่องโดนรีเซ็ต (Factory reset) แล้วเกิดอะไรขึ้น / ตั้งกลับยังไง
ที่หายไป: รูปทั้งหมด, Flash Kit และแอปที่ลงเพิ่ม, การล็อกออกงาน, Wi-Fi ที่บันทึก, USB debugging และการ Allow คอม · ชื่อเครื่องในตัวเครื่องหาย แต่คอมที่เคยตั้งชื่อจะเขียนคืนให้
1
ตั้งค่าเครื่องให้ผ่านหน้าแรก (ภาษา, Wi-Fi, ข้ามบัญชี Google ได้)
2
เปิด USB debugging ใหม่: เริ่มใช้ครั้งแรก ขั้น 1–2
3
เสียบเข้าเว็บ กด Always allow ที่เครื่องคอมที่เคยล็อกเครื่องนี้จะขึ้นป้าย หลุดล็อก · อาจรีเซ็ต
4
แท็บ เครื่อง > ตั้งเครื่องใหม่ทั้งหมดลง Flash Kit, ตั้งค่ามาตรฐาน, ต่อ Wi-Fi, ล็อกออกงาน ในคลิกเดียว
กันพนักงานรีเซ็ตจากปุ่มไม่ได้ 100% · ระบบกันรีเซ็ตด้วยบัญชี Google (FRP) ไม่ทำงานบน K3S ที่ลองแล้ว · ดูว่ารุ่นไหนรองรับได้ที่ แท็บ เครื่อง > ช่อง กันรีเซ็ต (FRP)
วิธีเข้าเมนู Recovery (หน้ารีเซ็ตเครื่อง)
1
ง่ายสุด: เสียบเว็บ แท็บ เครื่อง > กด เข้าเมนู Recovery
2
ด้วยปุ่ม: ปิดเครื่องให้สนิท แล้วกด Power + เพิ่มเสียง ค้างจนขึ้นโลโก้ ปล่อย Power แต่กดเสียงค้างไว้ไม่ขึ้นเมนู ให้ลอง Power + ลดเสียง · ขึ้นรูปหุ่นยนต์ "No command": กด Power ค้าง แล้วกดเพิ่มเสียง 1 ที
3
ในเมนู: ปุ่มเสียงขึ้น/ลง = เลื่อน · ปุ่ม Power = เลือกReboot system now = เปิดเครื่องปกติ · Wipe cache partition = ล้างแคช ไม่มีอะไรหาย · Wipe data/factory reset = ล้างเครื่อง ทุกอย่างหาย
