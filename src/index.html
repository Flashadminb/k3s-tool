ประวัติการลบ

เวลาเครื่องทำอะไรไฟล์ได้พื้นที่คืน
ทำครั้งเดียวต่อเครื่อง (และทำใหม่หลังรีเซ็ตเครื่องทุกครั้ง เพราะรีเซ็ตแล้วค่าจะหาย)
ขั้นที่ 1: เปิดโหมดนักพัฒนา (Developer options) ที่เครื่อง
1. เปิดแอป การตั้งค่า (Settings) ที่เครื่อง
2. เลื่อนลงล่างสุด แตะ เกี่ยวกับโทรศัพท์ (About phone)
บางรุ่นชื่อ "เกี่ยวกับอุปกรณ์" หรือ "ระบบ > เกี่ยวกับ"
3. หาบรรทัด หมายเลขบิวด์ (Build number) แล้ว แตะติดกัน 7 ครั้ง
ถ้าหาไม่เจอ ให้พิมพ์ "บิวด์" หรือ "Build number" ในช่องค้นหาบนสุดของหน้าตั้งค่า
4. ถ้าเครื่องถามรหัส ให้ใส่รหัสปลดล็อกหน้าจอ
5. จะขึ้นข้อความ "คุณเป็นนักพัฒนาแล้ว" (You are now a developer) แปลว่าสำเร็จ
ขั้นที่ 2: เปิด USB debugging
1. กลับไปหน้าแรกของ การตั้งค่า แตะ ระบบ (System)
2. แตะ ตัวเลือกสำหรับนักพัฒนา (Developer options)
บางรุ่นอยู่ที่หน้าแรกของการตั้งค่าเลย หรือค้นหาคำว่า "นักพัฒนา"
3. เลื่อนหา การแก้ไขข้อบกพร่อง USB (USB debugging) แล้ว เปิดสวิตช์
4. ขึ้นหน้าต่างถาม ให้กด ตกลง (OK)
5. (แนะนำ) ในหน้าเดียวกัน ถ้ามี ปิดการหมดเวลาการให้สิทธิ์ adb (Disable adb authorization timeout) ให้เปิดด้วย จะได้ไม่ต้องกดอนุญาตใหม่ทุก 7 วัน
ถ้าไม่เจอ "ตัวเลือกสำหรับนักพัฒนา" หรือเปิดสวิตช์ไม่ได้ (เป็นสีเทา) แปลว่าระบบบริษัทล็อกไว้ อย่าหาทางเลี่ยง ให้แจ้งไอที Flash
ขั้นที่ 3: เตรียมคอม (ทำครั้งเดียว)
1. ใช้ Google Chrome หรือ Microsoft Edge เท่านั้น (Firefox ใช้ไม่ได้)
2. ถ้าคอมเคยเปิดโปรแกรม adb ไว้ ต้องปิดก่อน ไม่งั้นเว็บจะต่อไม่ได้:
  1. กดปุ่ม ⊞ Windows ที่คีย์บอร์ด
  2. พิมพ์ cmd แล้วกด Enter จะขึ้นหน้าจอดำ
  3. พิมพ์บรรทัดนี้ (มีเว้นวรรค 1 ช่องหลังคำว่า cd) แล้วกด Enter
    cd C:\Users\Flash\Desktop\Best\platform-tools
  4. พิมพ์บรรทัดนี้ (มีเว้นวรรค 1 ช่องหลังคำว่า adb) แล้วกด Enter
    adb kill-server
  5. ปิดหน้าจอดำได้เลย
ถ้าไม่เคยใช้ adb บนคอมนี้ ข้ามข้อนี้ได้
⬇️ โหลด Platform-Tools (ต้องใช้เฉพาะคำสั่ง adb kill-server)
ขั้นที่ 4: เชื่อมต่อครั้งแรก
1. เสียบสาย USB ระหว่างเครื่องกับคอม (ต้องเป็นสายที่ส่งข้อมูลได้ ไม่ใช่สายชาร์จอย่างเดียว)
2. ปลดล็อกหน้าจอเครื่องไว้
3. ที่หน้าเว็บนี้ กดปุ่มสีฟ้า + เชื่อมต่อเครื่อง
4. จะมีหน้าต่างเล็กเด้งขึ้นบนเบราว์เซอร์ คลิกชื่อเครื่อง แล้วกด เชื่อมต่อ (Connect)
5. ดูที่หน้าจอเครื่อง จะขึ้น อนุญาตการแก้ไขข้อบกพร่อง USB? (Allow USB debugging?)
ติ๊ก อนุญาตจากคอมพิวเตอร์นี้เสมอ (Always allow) แล้วกด อนุญาต (Allow)
6. หน้าเว็บจะขึ้นชื่อเครื่องและพื้นที่ แปลว่าสำเร็จ
ครั้งต่อไป: แค่เสียบสาย หน้าเว็บจะเชื่อมต่อเครื่องที่เคยอนุญาตให้เอง ถ้าไม่ต่อเอง ให้กด + เชื่อมต่อเครื่อง
หลายเครื่อง: เสียบเพิ่มแล้วกด + เชื่อมต่อเครื่อง ทีละเครื่อง (แนะนำ USB hub ที่มีปลั๊กไฟของตัวเอง)
แก้ปัญหา: กดเชื่อมต่อแล้วไม่เห็นชื่อเครื่องในหน้าต่าง
  1. เช็กว่าเปิด USB debugging แล้วจริง (ขั้นที่ 2)
  2. เปลี่ยนสาย USB หรือเปลี่ยนช่อง USB ที่คอม
  3. รูดแถบแจ้งเตือนที่เครื่องลงมา แตะข้อความ USB แล้วเลือก โอนไฟล์ (File transfer)
  4. ถอดสาย รอ 3 วินาที เสียบใหม่
  5. ถ้ายังไม่ได้ ปิด USB debugging แล้วเปิดใหม่
แก้ปัญหา: ขึ้นว่าเครื่องถูกโปรแกรมอื่นใช้อยู่
  1. ทำขั้นที่ 3 ข้อ 2 (adb kill-server)
  2. ปิดโปรแกรมอื่นที่ใช้กับมือถือ เช่น Android Studio, scrcpy, Vysor
  3. ถ้าเปิดหน้าเว็บนี้ไว้หลายแท็บ ให้ปิดแท็บอื่นให้เหลือแท็บเดียว
  4. ถอดสายแล้วเสียบใหม่
แก้ปัญหา: ไม่มีหน้าต่าง "อนุญาต" ขึ้นที่เครื่อง / เคยกดปฏิเสธไป
  1. ปลดล็อกหน้าจอเครื่องไว้ระหว่างเชื่อมต่อ
  2. ถอดสายแล้วเสียบใหม่ กดเชื่อมต่ออีกครั้ง
  3. ถ้าเคยกดปฏิเสธ: ตัวเลือกสำหรับนักพัฒนา > เพิกถอนการให้สิทธิ์การแก้ไขข้อบกพร่อง USB (Revoke USB debugging authorizations) แล้วลองใหม่
หลังใช้งาน ควรปิด USB debugging ไหม
ถ้าใช้ทุกวัน เปิดค้างไว้ได้ แต่อย่าเสียบเครื่องกับคอมที่ไม่รู้จัก ถ้าบริษัทมีนโยบายให้ปิด ให้ปิดที่ ตัวเลือกสำหรับนักพัฒนา > การแก้ไขข้อบกพร่อง USB
