# K3S Tool

หน้าเว็บสำหรับเปิดใน Chrome/Edge บนคอม แล้วเสียบสาย USB กับเครื่อง PDA (K3S / Flash Kit) เพื่อลบรูปและขยะที่ทำให้พื้นที่เต็ม
ดูแลเครื่อง จัดการแอป และตั้งค่าเครื่อง โดยไม่ต้องพิมพ์คำสั่ง
ใช้ WebUSB + ไลบรารี `@yume-chan/adb` (ไม่ต้องติดตั้ง adb.exe)

**เปิดใช้งาน:** https://flashadminb.github.io/k3s-tool/ (อัปเดตอัตโนมัติทุกครั้งที่ push เข้า `main` ผ่าน GitHub Actions)

## สถานะ: v0.2 ยังไม่เคยทดสอบกับเครื่อง K3S จริง
ทุกปุ่มผ่านการทดสอบกับเครื่องจำลอง (`npm test`, คำสั่ง shell รันจริงบนโฟลเดอร์ปลอม) แต่ยังไม่เคยรันกับอุปกรณ์จริง
ต้องลองกับเครื่องจริงทีละปุ่มก่อนใช้งานจริง

หลายเครื่อง: กด "+ เชื่อมต่อเครื่อง" ทีละเครื่อง เครื่องที่เคยอนุญาตแล้วจะต่อให้เองเมื่อเสียบสาย
ข้อมูล (ประวัติ, ทะเบียน, ตั้งค่า) เก็บใน localStorage ของเบราว์เซอร์บนคอมเครื่องนั้น

## วิธีพัฒนา
```
npm install
npm run build        # ได้ dist/k3s-tool.html (ไฟล์เดียว ไม่ต้องใช้เน็ต)
npm test             # ทดสอบกับเครื่องจำลอง (ต้องมี Playwright + Chromium)
npm run serve        # เปิดที่ http://localhost:8080 (WebUSB ต้องเป็น secure context)
```
ก่อนใช้ต้องปิด `adb.exe` ที่รันค้าง (`adb kill-server`) ไม่งั้นเว็บจะขึ้นว่าเครื่องถูกใช้อยู่ (BUSY)

## โครงสร้าง
- `src/adb.js`  ชั้นต่อ ADB: `Device` (sh, push, pull, pullMany, reboot) หลายเครื่องพร้อมกัน, เชื่อมต่ออัตโนมัติ
- `src/app.js`  ทุกปุ่ม, คู่มือแก้ปัญหา (ตาราง `HELP`), dialog ยืนยัน
- `src/store.js`  localStorage: รุ่นเครื่อง (profiles), ประวัติ, ทะเบียน, แอปต้องห้าม, ตั้งค่ามาตรฐาน, CSV
- `src/appnames.js`  แปลงชื่อเทคนิคของแอปเป็นชื่อที่คนเห็น + แอปห้ามถอน
- `src/index.html`  หน้าจอ + คู่มือ
- `test/`  เครื่องจำลอง (`mock-adb.js`) + ชุดทดสอบ Playwright (`run.mjs`)

## คำสั่งที่ใช้บนเครื่อง (จุดที่ต้องเช็กกับเครื่องจริง)
| ปุ่ม | คำสั่ง | หมายเหตุ |
|---|---|---|
| นับ | `find DIR -type f -exec du -k {} + \| awk` , `df -k /sdcard` | ไฟล์เป็นหมื่นอาจช้า |
| ลบ success / fail | `find DIR -type f -delete` | ไม่ใช้ `rm -rf dir/*` (argument list too long) · ไม่มีโฟลเดอร์ = ไม่มีอะไรลบ |
| ลบขยะ | `find /sdcard -type f -name '.trashed-*' -delete` | ข้ามถังขยะ |
| ล้างแคช | `pm trim-caches 999G` | |
| ไฟล์ใหญ่ | `du -sk /sdcard/*`, `find /sdcard -size +1024k` | |
| ภาพ/วิดีโอหน้าจอ | `screencap -p`, `screenrecord --time-limit` | ไฟล์ชั่วคราวที่ `/data/local/tmp` |
| หน้าจอสด | screencap วน + `input tap/swipe/keyevent/text` | ประมาณ 1 ภาพ/วินาที · พิมพ์ภาษาไทยไม่ได้ |
| แอป | `pm list packages`, `pm uninstall`, `pm uninstall -k --user 0` (แอประบบ), `cmd package install-existing` | แอปใน `dumpsys device_policy` และชื่อมี flash ถอนไม่ได้ |
| รีสตาร์ทแอป Flash | `am force-stop` + `monkey -p PKG -c LAUNCHER 1` | หาแอปจาก `pm list packages \| grep -i flash` |
| ตั้งค่ามาตรฐาน | `settings put system/global ...` | |
| ติดตั้ง APK | push ไป `/data/local/tmp/` แล้ว `pm install -r` | อัปเดตทับได้ ลดเวอร์ชันไม่ได้ |
| ตั้งรูปหน้าจอ | push ไป `/sdcard/Download/` แล้ว `am start -a ATTACH_DATA` | อาจต้องแตะเองที่เครื่อง |
| รีเซ็ตเครื่อง | `am broadcast -a android.intent.action.FACTORY_RESET -p android` | น่าจะโดนปฏิเสธสิทธิ์ ถ้าไม่ตัดการเชื่อมต่อใน 10 วินาที จะแสดงวิธีทำมือ |

## สิ่งที่ยังต้องทำ / เสี่ยง
1. ทดสอบกับ K3S จริงทุกปุ่ม แล้วแก้ตามผล
2. ตรวจว่ารูปใน `success` ถูกอัปโหลดแล้วจริง ก่อนลบ (ตอนนี้ถือว่า success = อัปโหลดแล้ว ตามที่เห็นในแอป)
3. ถ้าระบบบริษัท (MDM) บล็อกฟีเจอร์ใด ห้ามหาทางเลี่ยง ให้ปรึกษาไอที Flash

## ข้อควรระวัง
- ปุ่มลบทุกปุ่มลบถาวร (ข้ามถังขยะ) มี dialog ยืนยัน
- กุญแจ ADB เก็บใน IndexedDB ของเบราว์เซอร์บนคอมเครื่องนั้น
