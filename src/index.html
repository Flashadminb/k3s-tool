ทำครั้งแรก (เครื่องใหม่หรือเครื่องที่เพิ่งรีเซ็ต)
  1. ที่เครื่อง: Settings > About phone > แตะ Build number 7 ครั้ง (เมนูชื่ออาจต่างกันตามรุ่น ลองค้นหา "Build number" ในช่อง Search)
  2. Settings > System > Developer options > เปิด USB debugging (ถ้าไม่เจอ Developer options อาจถูกระบบบริษัทล็อก ให้แจ้งไอที)
  3. บนคอม: ถ้าเคยเปิด adb ไว้ ให้พิมพ์ adb kill-server ก่อน
  4. เสียบสาย USB แล้วกด เชื่อมต่อเครื่อง เลือกเครื่อง K3S
  5. ที่เครื่องจะมี popup Allow USB debugging ให้ติ๊ก Always allow แล้วกด Allow
